# EPS PRO — Android (version 1.1)

Application Android en Kotlin + Jetpack Compose, bilingue français/arabe.

Fonctions :
- Calcul VMA à partir d'une distance et d'un temps.
- Estimation indicative du VO2max (approximation VO2max ≈ 3,5 × VMA).
- Calcul du temps par tour selon la longueur réelle de la piste, la VMA et le pourcentage d'intensité.
- Tableau de passage par tour avec temps du tour et temps cumulé.
- Le nombre de tours et la longueur du tour sont personnalisables (piste de 130 m, 200 m, 250 m, 400 m ou toute autre longueur).

## Ouvrir et construire
1. Installer Android Studio récent.
2. Ouvrir le dossier EPS_PRO_Android.
3. Laisser Gradle synchroniser les dépendances.
4. Lancer sur un émulateur ou un téléphone Android.
5. Pour générer l'APK : Build > Build Bundle(s) / APK(s) > Build APK(s).
